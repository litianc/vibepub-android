# Domain Docs

This repository uses one project context.

## Before exploring

- Read `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If these files do not exist, continue silently.

## Creation

- Create `CONTEXT.md` only when a project term has been clearly settled.
- Create an ADR under `docs/adr/` only for a hard-to-reverse and non-obvious trade-off.
- Keep `CONTEXT.md` as a glossary, without implementation details.
