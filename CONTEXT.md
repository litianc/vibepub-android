# VibePub

VibePub turns voice or text input into a tracked article workflow that can create a WeChat Official Account draft.

## Language

**Release Batch**:
A group of related changes that can pass testing and receive release approval without waiting for a later batch. A later batch may build on it.
_Avoid_: Version, wave

**Article Version**:
An immutable snapshot of one article's content, optionally linked to the earlier snapshot it revises.
_Avoid_: Release version, app version
